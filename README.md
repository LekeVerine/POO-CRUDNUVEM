# Como executar o projeto pelo Eclipse

### 1. Baixar o projeto
1. Acesse o repositório no GitHub.
2. Clique em **Code → Download ZIP**.
3. Extraia o arquivo ZIP em uma pasta do computador.

### 2. Importar o projeto
1. Abra o Eclipse.
2. Clique em **File → Import**.
3. Selecione **Maven → Existing Maven Projects**.
4. Clique em **Next**.
5. Em **Root Directory**, selecione a pasta do projeto que contém o arquivo `pom.xml`.
6. Clique em **Finish**.
7. Aguarde o Maven baixar as dependências.

### 3. Executar a aplicação
1. No Eclipse, localize a classe `RayApplication.java`, dentro do pacote `com.ray.ray`.
2. Clique com o botão direito sobre ela.
3. Selecione **Run As → Java Application**.
4. Aguarde a inicialização da aplicação.

### 4. Acessar o sistema

Abra o navegador e acesse:

**http://localhost:8080**
